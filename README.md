# SafeCircle

**Stay connected. Stay protected.**

SafeCircle is a personal-safety web/mobile app built with **Flutter** and **Firebase**.
Send an SOS with your live location, notify trusted contacts by WhatsApp or SMS,
record "I'm safe" check-ins, and review everything in an activity history.

Live demo: `https://<your-github-username>.github.io/SafeCircle/`

## Features

| Area | What it does |
| --- | --- |
| Authentication | Email/password sign-up and login, Google sign-in, password reset |
| SOS | Confirm, capture GPS location, save alert to Firestore, then notify contacts or call emergency services |
| Trusted contacts | Add, edit, remove; call, SMS or WhatsApp a contact in one tap |
| Safety check-in | Record "I'm safe" with an optional note and optionally tell your contacts |
| Location | Get current coordinates, open in Google Maps, copy link, share with contacts |
| Activity | SOS alert history (view on map, mark resolved, delete) and check-in history |
| Settings | Edit name, verify email, reset password, choose emergency number, log out |
| Dashboard | Live counts of contacts, weekly check-ins and active alerts |

## Project structure

```
lib/
  main.dart                  App entry, theme, auth gate
  theme.dart                 Colours, Material 3 theme, text-field style
  firebase_options.dart      Generated by FlutterFire CLI
  utils/helpers.dart         Pure functions (validation, links, messages, dates)
  services/app_services.dart Firestore, location and link-launching logic
  widgets/common.dart        Reusable UI (cards, stat cards, share sheet, dialogs)
  screens/
    auth_screen.dart         Login / sign-up
    dashboard_shell.dart     Responsive sidebar + bottom navigation
    home_page.dart           SOS, stats, quick actions, recent alerts
    contacts_page.dart       Trusted contacts
    location_page.dart       My location
    activity_page.dart       Alerts and check-ins history
    settings_page.dart       Profile and preferences
test/helpers_test.dart       Unit tests for the pure helpers
firestore.rules              Per-user Firestore security rules
.github/workflows/deploy.yml CI/CD to GitHub Pages
```

## Firestore data model

```
users/{uid}                  name, email, emergencyNumber
users/{uid}/contacts/{id}    name, relation, phone, createdAt
users/{uid}/alerts/{id}      type, status (Active/Resolved), latitude, longitude,
                             accuracy, mapsUrl, locationProblem, createdAt, resolvedAt
users/{uid}/checkins/{id}    status, note, createdAt
```

## Deploy (GitHub Pages)

1. Push this project to a GitHub repository named **SafeCircle** (the name is case-sensitive
   and must match `--base-href "/SafeCircle/"` in `.github/workflows/deploy.yml`).
2. GitHub repo -> **Settings -> Pages -> Source: GitHub Actions**.
3. Push to `main`. The workflow analyses, tests, builds and publishes the site.
4. Firebase Console -> **Authentication -> Settings -> Authorized domains** -> add
   `<your-github-username>.github.io` (required, otherwise login and Google sign-in fail on the live site).
5. Firebase Console -> **Firestore Database -> Rules** -> paste the contents of `firestore.rules` -> Publish.
6. Firebase Console -> **Authentication -> Sign-in method** -> enable **Email/Password** and **Google**.

## Notes

- Location needs HTTPS (GitHub Pages is HTTPS) and the user's permission.
- SMS and phone-call buttons work on phones; on desktop browsers use WhatsApp or copy the message.
- WhatsApp links need the phone number to include its country code (for example `+91...`).
